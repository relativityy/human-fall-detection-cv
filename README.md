# Разработка системы компьютерного зрения для детекции падения людей (Human Fall Detection)

Проект выполнен в рамках учебной практики. Включает в себя обучение нейросети YOLOv8m на специализированном датасете, оценку метрик и сравнительный анализ скорости работы различных архитектур на серверных CPU-мощностях Google Colab.

## 📊 Результаты тестирования и бенчмарки

### 1. Метрики обученной модели (YOLOv8m)
Тестирование проводилось на отложенной выборке из **892 изображений** (тестовый сплит `Human-Fall-2`).
* **Полнота (Recall):** `0.168` (16.8%)
* **Точность по mAP@0.5:** `0.092` (9.2%)
* **mAP@0.5:0.95:** `0.0335` (3.35%)

### 2. Сравнительный анализ производительности (Inference Latency)
Замеры времени обработки одного кадра при разрешении `640x640` на процессоре *Intel Xeon CPU @ 2.20GHz*:

| Архитектура модели | Время обработки кадра (мс) | Размер модели (МБ) |
| :--- | :--- | :--- |
| **SSD** | 1506.2 мс | ~140 МБ |
| **YOLOv8m (Наша)** | 2771.5 мс | ~51.5 МБ |
| **Faster R-CNN** | 6602.6 мс | ~167 МБ |
| **YOLO11m** | 15622.6 мс | ~53 МБ |
| **RT-DETR-L** | 24914.5 мс | ~64 МБ |

## 📂 Структура репозитория
* `fall_detection_training.ipynb` — рабочий блокнот Google Colab с процессом подготовки данных, обучения и валидации.
* `fall_demo_output.mp4` — демонстрационное видео с наложенной аналитической рамкой и триггером `!!! FALL DETECTED !!!` при фиксации падения.
* `evaluation_report.xlsx` — структурированный Excel-отчет с бенчмарками.
* `metrics_history.json` — сырые метрики последней эпохи обучения.
